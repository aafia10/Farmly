# Farmly — The Digital Infrastructure for Modern Farming

Farmly is an all-in-one digital platform connecting farmers, buyers, and agricultural services through modern, simple digital infrastructure.

## Monorepo Structure

```text
farmly/
├── frontend/    # Next.js 15+ App Router, React 19, TypeScript, Tailwind CSS, Framer Motion
└── backend/     # Placeholder for future backend APIs, services & database infrastructure
```

## Quick Start

### Frontend

To run the frontend application locally:

```bash
cd frontend
npm install
npm run dev
```

The frontend will be accessible at `http://localhost:3000`.

### Backend

The backend is currently in the architectural planning phase. See [`backend/README.md`](./backend/README.md) for details on planned services.
